# 0.2.0 release candidate status

Package metadata is 0.2.0. This candidate is ready for final cross-platform CI; signing and publication remain gated on the checklist. The atomic status and remaining count are maintained in the [0.2.0 release checklist](release-checklist-0.2.0.md).

## Delivered in the development branch

Styled inline fragments and atomic text-flow `inline-block` boxes; Unicode grapheme-cluster font fallback, including tested monochrome emoji ZWJ sequences; CFF-outline OTF, WOFF/WOFF2, variable `wght`/`wdth` instances, CSS `font-stretch` and opt-in synthetic bold/italic; source-aware structured missing-glyph exceptions; production RustyBuzz shaping for tested Latin, combining marks, Arabic, Hebrew, mixed LTR/RTL text and explicit bidi controls with logical PDF `/ActualText`; justify/indent/whitespace handling and manual soft-hyphen breaks; contextual CSS lengths, percentage edges and modern alpha colors; `visibility`, `opacity`, block/paragraph/Flex/Grid min/max dimensions, overflow clipping, margin collapsing and per-side rounded/dashed/dotted borders; complete 0.2 table layout with constrained columns, collapsed/separate borders, nested tables, fragmented rowspans, connected spans in repeating sections and opt-in presentational hints; paragraph `orphans`/`widows`; WebP/GIF decoding, raster soft masks, JPEG passthrough, EXIF orientation, object fitting/positioning and opt-in DPI downsampling; vector SVG Form XObjects with bounded validation; block-level relative/absolute/fixed positioning, repeated fixed layers, integer z-order, clipping and affine translate/scale/rotate transforms; extended Flex reverse/wrap/sizing/alignment and Grid track/placement/span/alignment support with defined page-boundary behavior; composable named-page selectors, nested counters, text running content/named strings, bleed and crop marks; internal/external PDF links, inline destinations, hierarchical heading outlines, byte attachments and configurable UTC metadata dates; filterable diagnostics, strict typed errors, render limits/cancellation and render stats. The legacy Python entry points remain callable.

## Verification completed locally

- Rust: 82 unit/integration tests pass using `cargo test --no-default-features --locked`, including the injected panic-boundary guard tests.
- Python: 103 tests pass against a freshly built macOS arm64 CPython 3.10+ ABI3 wheel installed into an isolated target directory (executed on CPython 3.13), including compatibility, diagnostic-policy, adversarial-input, source-location regressions and fourteen rendered visual-reference pages spanning ten cases. The final multi-OS/architecture wheel matrix remains a CI gate.
- `cargo fmt --all --check` and `cargo clippy --locked --all-targets -- -D warnings` pass locally.
- `maturin sdist` builds the source archive; its `PKG-INFO` includes the project homepage, source and documentation URLs.
- The published alpha commit passed the seven-target Linux, macOS and Windows wheel matrix and installed-wheel ABI3 tests on CPython 3.10–3.14. The post-alpha box-model commit has additionally passed a clean macOS arm64 wheel test; its full matrix remains a final-candidate gate.
- Repeated whole-document layouts produce byte-identical PDF output in the deterministic regression test; checked-in visual references cover trim/crop geometry, first/left/right/blank pages, counters/running/fixed content, repeated headers, rowspans/nested tables, font fallback/shaping/WOFF2, typography/paint/links, paragraph pagination, layout modes and raster/vector image resources. PDF structure-only features are covered by pypdf assertions.
- Diagnostic filters, callbacks, typed strict errors, mapped source-token locations and the guarded Python FFI have installed-wheel tests. All four libFuzzer targets compile and complete local smoke runs; coverage-guided sanitizer runs are configured in scheduled/manual nightly CI.
- An independent-process benchmark records throughput and confirms the bounded resource LRU remains within its byte cap.

## Performance comparison

The same 50-repeat corpus was run in separate processes against installed wheels from git `9569d5e` and this development branch on macOS arm64, CPython 3.13. Values are warm medians in milliseconds; the comparison is a local measurement, not a cross-platform guarantee.

| Document | Layout before → after | PDF export before → after | PDF bytes before → after |
| --- | ---: | ---: | ---: |
| Simple | 0.288 → 0.132 | 0.168 → 0.167 | 14,068 → 14,066 |
| Forced break | 0.964 → 0.366 | 0.285 → 0.285 | 14,403 → 14,393 |
| Table | 2.714 → 1.683 | 0.604 → 0.613 | 20,934 → 20,820 |

Peak RSS was 46.3 MB before and 48.3 MB after (+4.3%) in the earlier processes. The isolated grapheme fallback and `font-stretch` comparison used 1,000 repeats, the same corpus and Python environment, and sequentially installed wheels. Warm layout/export medians in ms were: simple 0.135/0.190 → 0.137/0.192; forced break 0.348/0.333 → 0.350/0.334; table 1.770/0.703 → 1.789/0.709. After explicit bidi-control support, the opt-in shaping path measured 1.319, 4.233 and 10.060 ms warm layout on simple, forced-break and table documents, respectively, versus 1.414, 4.409 and 10.529 ms in the preceding run. Export medians were 0.193, 0.338 and 0.730 ms. The completed table rowspan/footer/vertical-align slice was measured separately over 100 repeats against the immediately preceding installed wheel: the table warm layout median changed from 1.696 to 1.929 ms (+13.7%), while export changed from 0.670 to 0.672 ms (+0.3%); simple and forced-break changes stayed near 1%. Peak RSS changed from 61.1 to 64.7 MB (+5.8%).

The inline-block, manual-hyphenation and table-spacing slice was measured over 20 repeats against an independently built wheel from git `e4d60a8`. Warm layout/export medians in ms were: simple 0.202/0.275 → 0.140/0.179; forced break 0.451/0.418 → 0.365/0.311; table 2.192/0.741 → 2.127/0.654; SVG 0.027/0.125 → 0.028/0.117. Peak RSS changed from 62.0 to 63.2 MB (+2.0%). No layout, export or RSS regression gate was exceeded. The benchmark includes separate cold and warm render, layout, export, thread throughput, RSS and PDF size. Independent-process stress results are recorded in [the benchmark report](benchmark.md). The locally verified macOS arm64 ABI3 alpha wheel SHA256 is `4a415080317bfcee37af20ff2cd16c97765cebe516e0d1361fc723fa0e4c2bca` (normalized package version 0.2.0a1). Cross-platform release checksums are generated separately from the CI artifacts.

The completed table slice was compared with `c34ad5b` using six alternating pairs of independently installed wheels and 50 warm repeats per process. Median layout/export changes were: simple -4.8%/-7.1%; forced break +0.7%/+0.0%; table -0.9%/-6.3%; SVG +0.4%/+1.7%. Median peak RSS changed by -0.6%. Individual short-run timings were noisy, so the release gate uses the median paired change; no 15% layout, 10% export or 20% RSS gate was exceeded. The final locally installed macOS arm64 table-slice wheel has SHA256 `13e126c4e1a3e7cc58b22350e9e2726e12d81d667d7f997b802984cb996a200c`.

## Release blockers

The remaining blockers are tracked as individual unchecked items in the [release checklist](release-checklist-0.2.0.md). Completed items are retained there so each implementation block visibly reduces the open count. Partial capability labels are boundaries for callers and are not used as the progress counter. External full-matrix CI, release-tag signing and publication require the final candidate commit and authorized GitHub release credentials.

The release should be tagged only after the capability matrix, mandatory CI fixtures, performance gates and distribution artifacts are complete. The tested Rust toolchain and declared MSRV are 1.98.1.
