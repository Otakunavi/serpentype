# Serpentype 0.1 capability matrix

The ordinary mode returns `PreparedDocument.warnings` with `code` and `message` for unsupported syntax. `strict=True` raises `ValueError` on these diagnostics. Missing fonts/glyphs, unreadable files, impossible page geometry, and oversized repeating headers always raise errors. Unsupported constructs may be skipped in ordinary mode; use strict mode for controlled templates.

| Area | Implemented | Values and exact behavior |
| --- | --- | --- |
| HTML blocks | `div`, `section`, `article`, `p`, `h1`–`h6` | Normal document flow; nested block children in source order. No browser margin collapsing. |
| HTML inline | text, `span`, `strong`, `b`, `em`, `i`, `br` | Inherited text styling; `br` forces a line. Whitespace collapses. |
| Tables | `table`, `thead`, `tbody`, `tfoot`, `tr`, `th`, `td` | `<thead>` rows repeat after page breaks. Rows and cells are laid out by text lines. `tfoot` flows as body rows. `rowspan` and `colspan` warn/error. |
| Images | `img src` | Local PNG/JPEG path relative to `Renderer.base_dir`; intrinsic dimensions are CSS px at 0.75 pt/px unless styled. Source bytes are loaded during layout. PNG alpha is composited on white. |
| Rules | type, `.class`, `#id`, compounds, attribute equality `[data-print="paged"]`, direct child `>`, descendant selectors, comma lists | Specificity and source order with `!important`; inline styles participate in the same cascade. `@media print` rules apply during PDF layout. Other media queries and custom properties warn/error. |
| Text | `font-family`, `font-size`, `font-weight`, `font-style`, `line-height`, `color`, `text-align` | Explicit family list fallback, exact registered weight/style. Left/center/right alignment. Font size and line height in `pt`, `px`, `mm`, `cm`, `in`; line height also a unitless multiplier. Colors: six-digit/three-digit hex, black, white, red, blue, green, gray/grey, yellow. |
| Box | `margin`, `margin-*`, `padding`, `padding-*`, `border`, `border-width`, `border-color`, `background`, `background-color`, `width` | 1–4 length shorthand; solid borders only; rectangles drawn for paragraphs and cells. Width works for text blocks, tables, cells and images. Image borders/backgrounds warn. `height:auto`, `aspect-ratio:1`, and percentage `max-width`/`max-height` work for images; fixed height works for column flex containers. |
| Display | `display: none`, `flex`, `grid` | `none` removes the subtree. Column flex supports `align-items:center`, `justify-content:center`, and padding. Grid supports equal columns with `repeat(n, 1fr)` and `align-items:center`; a grid row must fit on one page. Other Flex/Grid behavior is not implemented. |
| Pages | `@page`, named pages, `@page :first`, `page: name`, six top/bottom margin boxes | A4 portrait/landscape or two explicit dimensions, 1–4 length margins, `page-orientation: rotate-left`/`rotate-right`/`upright`. Margin box `content` supports strings plus `counter(page)` and `counter(pages)`, with font family, size, and color. Margin box properties follow importance, page-selector specificity, and source order; a named page outranks `:first` at equal importance. For compatibility with the source stylesheet, the `landscape` size keyword takes precedence over a simultaneous 90-degree `page-orientation`; other page sizes still rotate the laid-out page and its margin boxes. |
| Breaks | `break-before: page`, `break-after: page`, `break-inside: avoid`; `page-break-before/after: always`, `page-break-inside: avoid` | Before/after apply to text blocks, containers, tables and images. Avoid applies to text blocks and tables; table rows are already kept whole when possible. `auto` is accepted. A `.pagebreaker` class has no built-in meaning. Avoid is relaxed for elements taller than the full content area. |
| Fonts | `register_file`, `register_bytes`, local `@font-face` `url(...)` | Static TrueType outlines in TTF or OpenType wrappers; face index zero. Variable fonts and CFF-outline OTF are rejected. No synthetic bold/italic or silent system fallback. |
| PDF | Unicode TrueType text, vector boxes, embedded RGB images | CIDFontType2 with ToUnicode mapping and embedded subsets of the used glyphs; repeated export uses the same display list. Transparency, links, annotations and forms are absent. |

## Important limits

- Text is measured with glyph advances but **complex shaping, kerning, ligatures, bidirectional layout, hyphenation and vertical writing are not implemented**. Cyrillic works with the bundled Noto Sans. Scripts that need shaping require a later version.
- Inline objects are flattened into block lines; full CSS inline formatting, floats, general Flex/Grid algorithms, positioning, transforms, overflow clipping and nested table cells are not implemented.
- CSS `content` is parsed after any application template engine has run. Serpentype does not evaluate Jinja expressions such as `{{ cameral.notice.reg_number }}`; render them before passing the stylesheet. Register the `Times Newer Roman` face explicitly when using `page_definition.css`; Serpentype never picks a system substitute silently.
- Table column widths use a documented heuristic based on explicit widths and longest words; this is not browser auto table layout. All border edges are drawn independently; `border-collapse` is unsupported.
- An ordinary row that fits in a page after the header moves whole when possible. A taller row splits on text lines. A cell's background/border is redrawn for each fragment.
- Active prepared documents and font registrations may retain bytes beyond the evictable font and image cache limits. No interprocess cache is provided.
- PDF export subsets every used TrueType font and embeds only the glyphs needed by the document. Text extraction is checked independently in the PDF stress test.
