# Capability matrix for the 0.2.0 development branch

`serpentype.capabilities()` returns the machine readable matrix. `Renderer.supports(name)` is true for `full` and `partial`; callers should inspect the level before depending on complete CSS behavior. Package version 0.2.0-alpha.1 is an explicitly incomplete prerelease while the final 0.2.0 gates remain open.

| Capability | Level | Tested behavior and boundary |
| --- | --- | --- |
| Basic inline text | partial | `span`, `strong`/`b`, `em`/`i`, `u`, `a`, `br`, `sup`, `sub` retain their text styles in the line; mixed sizes affect line height. `inline-block` currently accepts text content but does not form an independent CSS box. |
| Font fallback | partial | Unicode grapheme clusters select one registered face before shaping, so combining sequences and tested emoji ZWJ sequences are not split between fonts. Tested Cyrillic, extended Latin, Arabic and monochrome emoji fallback. Missing glyphs raise `MissingGlyphError`, a `ValueError` subclass with code point, character, requested family, weight/style, selected fallback and line/column for literal characters in string HTML. Source filenames and positions for character references remain open. |
| Font formats and faces | partial | Static TrueType and CFF-outline OTF, WOFF and WOFF2 containers, variable `wght`/`wdth` instances, CSS `font-stretch` keywords/percentages and configurable synthetic bold/italic are tested through PDF export. Use `Renderer(synthetic_bold=True, synthetic_italic=True)` to opt in to synthetic faces. Variable axes other than `wght`/`wdth` and comprehensive font-format coverage remain open. |
| Font shaping and mixed bidi | experimental | `Renderer(experimental_shaping=True)` enables RustyBuzz shaping and Unicode bidi ordering. Tested Latin ligatures/kerning, combining marks, Arabic, Hebrew, numbers and punctuation, inline direction boundaries, grapheme fallback, and explicit embedding/isolate controls. Bidi controls participate in UAX #9 ordering without requiring or emitting glyphs. Mixed lines carry exact visible logical text in PDF `/ActualText`; pypdf and pdfminer currently ignore that marked content and may omit a space adjacent to RTL text during extraction. The opt-in path is substantially slower than the default path. |
| Text wrapping and alignment | partial | `justify`, positive length `text-indent`, `overflow-wrap`, `word-break`, `white-space`, Unicode whitespace and nonbreaking spaces are parsed. Oversized lines raise a controlled error. Soft hyphen and full CSS line breaking remain unsupported. |
| CSS lengths and colors | partial | `em`, `rem`, simple additive/subtractive `calc()`, percentage widths, named colors, opaque RGB/HSL and border width keywords. Percentage heights are resolved for images and fixed-height flex columns. Alpha channels and general percentage margins remain unsupported. |
| Tables | partial | Auto/fixed column widths, `colspan`, body `rowspan`, cell `vertical-align: top/middle/bottom`, repeated `thead` and `tfoot`, row fragments with continued cell borders/backgrounds, and a guard against a header without a data row. Connected rowspan groups stay on one page when they fit; a group taller than the available page area returns a controlled error. Rowspan inside repeating header/footer groups, rowspan fragmentation across pages, collapsed-border conflict resolution and nested tables remain unsupported. |
| Images | partial | PNG, JPEG, first frame of GIF, WebP, pixel limit, local files. Raster alpha is exported with a PDF soft mask. Unrotated JPEG bytes are embedded with DCTDecode; EXIF-oriented JPEGs are decoded and transformed. Object-fit remains unsupported. |
| SVG | partial | `resvg` renders local and base64 `data:` SVG into a transparent, DPI-controlled raster fallback. Tested `viewBox`, groups, transforms, shapes, gradients, embedded raster data images and registered-font text. External references, browser content such as `foreignObject`, invalid SVG and unavailable text glyphs return errors. Vector PDF export and complete SVG feature coverage remain open. |
| CSS positioning | partial | `position: relative` moves painted block content, links and destinations without moving normal flow. Inline relative positioning, absolute/fixed positioning and transforms remain unsupported. |
| Flex/Grid | partial | Equal-column grid and limited flex layout accept `gap`, `row-gap` and `column-gap`. Grid rows cannot split across pages; fixed-height flex columns cannot split. Flex grow/shrink and general grid tracks remain unsupported. |
| Paged media | partial | Named pages, `:first`, `:left`, `:right` and `:blank` page styles/margin boxes, simple and left/right/recto/verso page breaks, `break-inside: avoid`, `orphans`/`widows`, six margin boxes and page counters. Side breaks insert blank pages when necessary. Page selector combinations, running elements and strings, bleed and crop marks remain unsupported. |
| PDF links | partial | External HTTP(S) and `mailto:` annotations; internal links to `id` on paragraphs, headings and images with named PDF destinations. Other anchor placements and bookmarks remain unsupported. |
| PDF metadata | partial | `<title>`, author/subject/keywords `<meta>` and `<html lang>` are exported. Timestamps and attachments are not implemented. |
| Deterministic PDF | partial | Object/resource order, font subset names and compression are stable; repeated whole-document layouts are byte-identical in regression tests. No timestamps or generated document identifiers are written. Cross-platform byte identity is not established. |
| Diagnostics | partial | Severity, code, message, optional context fields, occurrence count, JSON serialization and deduplication are public. Source positions, filters, callbacks and diagnostic limits remain open. Browser-only `cursor`, `caret-color` and `user-select` are ignored without repeated warnings. |
| Resource loading | partial | Core accepts local image and `@font-face` paths, plus base64 raster/SVG `data:` images. `RenderLimits(restrict_base_dir=True)` confines local resources to `base_dir`, including symlinks. Python `ResourceLoader` supports file, data, package, in-memory mapping, callback and opt-in HTTP(S) with scheme/host, redirect, timeout and byte/count limits. `HTML` and `CSS` accept `resource_loader` or `url_fetcher`; direct Rust-backed `Renderer` does not yet accept this loader. |
| Limits and cancellation | partial | Public `RenderLimits` and `CancelToken` enforce input/node/CSS rule/page/image pixel/resource byte/layout work bounds and poll cancellation in layout/export. Limits are typed Python errors; some malformed-input errors remain `ValueError`. |
| Render stats | partial | Parse, CSS, layout and last export times; page/node/glyph/cache counts; retained cache bytes; output size and diagnostic count. Experimental `shaping_time_ms` currently includes inline line construction and bidi work, so it is an upper bound for shaping itself. |

The renderer never substitutes a system font. An unavailable glyph, unreadable resource, impossible line width or page geometry returns a controlled exception. Ordinary mode may still ignore unsupported HTML tags; use `strict=True` to fail on diagnostics during parsing.

## Page break behavior

`break-before` is applied before the element and `break-after` schedules a break before the next element. If both apply at a boundary, `break-before` chooses the side; the flow inserts one page break and, if necessary, one blank page to reach the requested side. Right/recto means odd page numbers; left/verso means even page numbers. An explicit break takes precedence over `break-inside: avoid`; avoid moves a fitting paragraph or table to the next page, then relaxes for content taller than a page. `orphans` and `widows` move paragraph lines before drawing when feasible. Table headers repeat before row fragments; a header too tall to leave room for a data line raises an error. Other CSS break conflict rules are not implemented.
