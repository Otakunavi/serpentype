# Capability matrix for the 0.4.0 release

`serpentype.capabilities()` returns the machine readable matrix. `Renderer.supports(name)` is true for `full` and `partial`; callers should inspect the level before depending on complete CSS behavior. The WeasyPrint-shaped API preserves common call forms, not rendering equivalence; see [the compatibility limits](weasyprint_compat.md).

| Capability | Level | Tested behavior and boundary |
| --- | --- | --- |
| Basic inline text | partial | `span`, `strong`/`b`, `em`/`i`, `u`, `a`, `br`, `sup`, `sub` retain their text styles in the line; mixed sizes affect line height. `inline-block` is an atomic inline formatting box with its own width, min/max constraints, padding, border, background, margins and internally wrapped inline text. Block descendants inside an inline-block are currently flattened into its internal text flow. |
| Font fallback | partial | Unicode grapheme clusters select one registered face before shaping, so combining sequences and tested emoji ZWJ sequences are not split between fonts. Tested Cyrillic, extended Latin, Arabic and monochrome emoji fallback. Missing glyphs raise `MissingGlyphError`, a `ValueError` subclass with code point, character, requested family, weight/style, selected fallback, source filename and line/column, including numeric/common named character references. |
| Font formats and faces | partial | Static TrueType and CFF-outline OTF, WOFF and WOFF2 containers, variable `wght`/`wdth` instances, CSS `font-stretch` keywords/percentages and configurable synthetic bold/italic are tested through PDF export. Use `Renderer(synthetic_bold=True, synthetic_italic=True)` to opt in to synthetic faces. Variable axes other than `wght`/`wdth` and comprehensive font-format coverage remain open. |
| Font shaping and mixed bidi | full | RustyBuzz shaping and Unicode bidi ordering are always enabled. Tested Latin ligatures/kerning, combining marks, Arabic, Hebrew, numbers and punctuation, inline direction boundaries, grapheme fallback, and explicit embedding/isolate controls. Bidi controls participate in UAX #9 ordering without requiring or emitting glyphs. Mixed lines carry exact visible logical text in PDF `/ActualText`; some third-party extractors ignore that marked content and may omit a space adjacent to RTL text. The former `experimental_shaping` argument remains a compatibility no-op. |
| Text wrapping and alignment | partial | `justify`, positive length `text-indent`, `overflow-wrap`, `word-break`, `white-space`, Unicode whitespace and nonbreaking spaces are parsed. `hyphens:manual` uses a soft hyphen only when that opportunity is selected; `hyphens:none` suppresses it in both shaped and default text paths. Oversized lines raise a controlled error. Full CSS/Unicode line breaking remains unsupported. |
| CSS lengths and colors | partial | `em`, `rem`, simple additive/subtractive `calc()`, percentage widths/heights/margins/padding, named colors, RGB/HSL comma or space syntax, slash alpha, `rgba()`/`hsla()` and border width keywords. Alpha and cumulative element `opacity` use deterministic PDF `ExtGState` resources. |
| CSS box sizing and visibility | partial | Paragraph, general block, table, Flex and Grid containers apply `content-box`/`border-box` and fixed/percentage min/max constraints in their supported layout modes. `overflow:hidden` clips painting and advances normal flow by the constrained box; `overflow:visible` retains content. Sibling and parent/child margins collapse with positive and negative values. Per-side solid/dashed/dotted borders and rounded backgrounds/clips are exported. `visibility:hidden` retains layout while suppressing paint and links. Multi-page clipped blocks return a controlled error. |
| Tables | full | Auto/fixed layout; fixed, percentage and min/max constraints for tables, `<colgroup>`, `<col>` and cells; `colspan`/`rowspan`; cell vertical alignment; nested tables; repeated `thead`/`tfoot`; and an opt-out for footer repetition with `tfoot { display:table-row-group }`. Oversized rowspan groups fragment between complete text lines with continued backgrounds and borders. Connected rowspans in repeating groups are repeated together. Separate borders apply one/two-value `border-spacing`; collapsed solid borders resolve conflicts by width and document order and paint each shared edge once. `word-break`, `overflow-wrap` and `white-space` affect intrinsic column widths. With `presentational_hints=True`, table width/height, `cellpadding`, `cellspacing`, align/valign and border attributes are lower-priority hints. A nested table is atomic for outer-row pagination and returns a controlled error if it cannot fit one cell fragment. |
| Images | partial | PNG, JPEG, first frame of GIF, WebP, pixel limit, local files, `object-fit: fill/contain/cover/none/scale-down`, keyword/percentage/length `object-position`, and opt-in `max_image_dpi` downsampling. Raster alpha is exported with a PDF soft mask. Unrotated JPEG bytes are embedded with DCTDecode; EXIF-oriented JPEGs are decoded and transformed. |
| SVG | partial | Supported local and base64 `data:` SVG is retained as a vector PDF Form XObject; filter subtrees and embedded raster images remain raster where required. `resvg` supplies bounded validation and the transparent preview fallback used during layout. Tested `viewBox`, groups, transforms, shapes, gradients, embedded raster data images and registered-font text. External references, browser content such as `foreignObject`, invalid SVG and unavailable text glyphs return errors. |
| CSS positioning | partial | Block-level `relative`, `absolute` and `fixed` positioning is supported. Absolute boxes use the nearest positioned block/Flex/Grid content box (or the page content box), percentage insets resolve against it, and `overflow:hidden` clips positioned descendants. Fixed boxes are recalculated and repeated on every page. Integer `z-index` orders positioned layers around normal content. `translate` with length offsets, `scale` and `rotate` compose around the painted box center and transform PDF links/destinations with the content. Inline positioning, percentage translate values, custom `transform-origin`, sticky positioning and full stacking-context isolation remain unsupported. |
| Flex/Grid | partial | Flex supports row/column and reverse directions, nowrap/wrap/wrap-reverse, fixed/percentage `flex-basis`, grow/shrink, percentage item widths, `justify-content`, `align-items`, `align-self`, `align-content` and gaps. An auto basis uses the declared main size, then a deterministic equal share when intrinsic measurement is unavailable. Grid supports fixed/percentage/`fr`/`auto`/`minmax()`/integer `repeat()` tracks, row-major auto placement, positive explicit line placement, spans, item/content alignment and gaps; `auto` shares remaining space rather than performing browser intrinsic track sizing. Flex rows and Grid rows are atomic page units and move before painting when their declared cross-size does not fit. Unsized column-flex children use normal child fragmentation; explicitly sized items are atomic. Height-constrained Flex/Grid containers cannot cross pages. Named lines, dense placement, implicit track declarations and full intrinsic sizing remain unsupported. |
| CSS multi-column | partial | `column-count` and `column-gap` balance inline text into equal-width side-by-side columns when the content is inline-only. Complex block descendants and full multi-page column balancing remain unsupported and are diagnosed. |
| Paged media | partial | Named pages compose with multiple `:first`, `:left`, `:right` and `:blank` pseudo-classes; page declarations cascade by importance, selector specificity and source order. Auto-width ancestor frames follow named page dimensions, including landscape pages. Supports simple and left/right/recto/verso page breaks, `break-inside: avoid`, `orphans`/`widows`, six margin boxes and page counters. Margin-box `font` shorthand accepts a size and family list. At a boundary, `break-before` wins over a prior `break-after`; a single break is made and a blank page is added if needed to reach the requested side. Nested `counter-reset`/`counter-increment` work with `counter()`/`counters()`. `string-set: name content()` snapshots text, and `position: running(name)` plus `element(name)` place flattened text in margin boxes; first/start/last selection and full element layout are not supported. `bleed` expands the PDF page boxes and `marks: crop` paints crop marks; accepted dimensions are supported absolute CSS lengths. |
| PDF links and outlines | partial | External HTTP(S) and `mailto:` annotations; internal links and named destinations for IDs on supported HTML elements, including inline IDs, and legacy `<a name>` targets. Non-empty `h1`–`h6` headings export as nested PDF outline entries. Arbitrary author-defined outline entries and unsupported/empty inline positioning cases are not provided. |
| PDF metadata and attachments | partial | `<title>`, author/subject/keywords `<meta>` and `<html lang>` are exported. `to_pdf(attachments={filename: bytes}, creation_date=..., modification_date=...)` embeds byte attachments (as `application/octet-stream`) and accepts PDF UTC timestamps in `D:YYYYMMDDHHmmSSZ` form. Attachments are limited to 100 MB total. |
| Deterministic PDF | partial | Object/resource order, font subset names and compression are stable; repeated whole-document layouts are byte-identical in regression tests. No timestamps or generated document identifiers are written unless dates are explicitly supplied. An exact SHA256 fixture is checked on native Linux, macOS and Windows wheel jobs; byte identity across all release targets remains pending a successful full release matrix. |
| Diagnostics | partial | Severity, code, message, context fields, occurrence count, JSON serialization, deduplication, code/severity allow/deny filters, callbacks and maximum diagnostic count are public. Parser, CSS and HTML-conversion diagnostics map to original HTML/CSS tokens; source-addressable resource and layout failures include source/line/column on typed Python exceptions, including resource limits, malformed markup/CSS, strict-mode errors and margin-box missing glyphs. Input-wide cancellation and aggregate render-budget failures do not have a unique source token. Browser-only `cursor`, `caret-color` and `user-select` are ignored without repeated warnings. |
| Diagnostic source locations | full | HTML tags, CSS declarations/parser diagnostics, malformed input, strict-mode failures, resource loading and layout/missing-glyph errors retain a source label and 1-based line/column. HTML comments/raw-text elements are excluded from the token offset map; source-name overrides are preserved. Input-wide cancellation/aggregate limits intentionally have no unique token. |
| Resource loading | partial | Core accepts local image and `@font-face` paths, plus base64 raster/SVG/font `data:` resources. `RenderLimits(restrict_base_dir=True)` confines local resources to `base_dir`, including symlinks. Python `ResourceLoader` supports file, data, package, in-memory mapping, callback and opt-in HTTP(S) with scheme/host, redirect, timeout and aggregate byte/count/cache limits; `cache_size` and `cached_resources` expose current bounded LRU use. `Renderer`, `HTML` and `CSS` accept `resource_loader`; compatibility objects also accept `url_fetcher`. |
| Limits and cancellation | partial | Public `RenderLimits` and `CancelToken` enforce input/node/CSS rule/page/image pixel/resource byte/layout work bounds and poll cancellation in resource reads, layout and PDF export. Limits, cancellation, missing glyphs and strict-mode diagnostics have dedicated typed Python exceptions; some malformed-input errors remain `ValueError`. Rust layout and PDF work are guarded against unwinding across the Python FFI boundary. |
| Render stats | partial | Parse, CSS, layout and last export times; page/node/glyph/cache counts; retained cache bytes; output size and diagnostic count. `shaping_time_ms` includes inline line construction and bidi work, so it is an upper bound for shaping itself. |

The renderer never substitutes a system font. An unavailable glyph, unreadable resource, impossible line width or page geometry returns a controlled exception. Ordinary mode may still ignore unsupported HTML tags; use `strict=True` to fail on diagnostics during parsing.

## Page break behavior

`break-before` is applied before the element and `break-after` schedules a break before the next element. If both apply at a boundary, `break-before` chooses the side; the flow inserts one page break and, if necessary, one blank page to reach the requested side. Right/recto means odd page numbers; left/verso means even page numbers. An explicit break takes precedence over `break-inside: avoid`; avoid moves a fitting paragraph or table to the next page, then relaxes for content taller than a page. `orphans` and `widows` move paragraph lines before drawing when feasible. Table headers repeat before row fragments; a header too tall to leave room for a data line raises an error. Other CSS break conflict rules are not implemented.
