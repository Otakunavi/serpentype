# Migration notes for 0.2.0

Existing Python call forms continue to work. `PreparedDocument.warnings` remains available; `diagnostics` exposes the same entries with severity, optional context and occurrence counts. Duplicate warnings are now combined. `cursor`, `caret-color` and `user-select` are ignored without a warning.

`Renderer` optionally accepts `diagnostic_allow_codes`, `diagnostic_deny_codes`, `diagnostic_allow_severities`, `diagnostic_deny_severities`, `max_diagnostics` and `diagnostic_callback`. Filters run before callbacks and strict-mode checks. `strict=True` raises `StrictModeError` for diagnostics that remain after filtering. Current parser, CSS and HTML-conversion diagnostics include token-level `source`, `line` and `column`; some resource/layout errors still need complete source spans. `ResourceLoader.cache_size` and `.cached_resources` report current LRU occupancy.

`Renderer(fonts=..., base_dir=..., strict=...)` retains its positional and keyword parameters. An optional `limits=RenderLimits(...)` parameter adds bounds. `Renderer.layout(..., cancel_token=CancelToken())` and `PreparedDocument.to_pdf(cancel_token=...)` accept optional cancellation. Resource and cancellation failures raise subclasses of `ValueError`: `RenderLimitError` and `RenderCancelledError`.

`RenderLimits(restrict_base_dir=True)` optionally confines local images and `@font-face` files to the canonical `base_dir`; symlinks that leave it are rejected. The default is `False` to preserve existing absolute and parent-relative local paths.

Raster images can now use base64 `data:image/png`, `image/jpeg`, `image/gif` and `image/webp` URLs. SVG also accepts `data:image/svg+xml;base64,...` and local `.svg` files. The declared raster media type must match the payload and decoded bytes count against `max_resource_bytes`.

Font selection now chooses the nearest registered weight/style and then another registered face for a complete Unicode grapheme cluster. An exact face is still preferred. Registered static TTF, CFF-outline OTF, WOFF and WOFF2 fonts can be exported to PDF; variable `wght` and `wdth` fonts use the requested weight and CSS `font-stretch`. `Renderer(synthetic_bold=True, synthetic_italic=True)` enables PDF synthetic faces when a matching registered face is unavailable. These flags default to `False` for compatibility. A registered monochrome emoji font can provide glyph fallback, including tested ZWJ sequences. Missing glyphs raise `MissingGlyphError`, which remains a `ValueError` subclass and exposes code point, character, requested family, weight/style, selected fallback, source filename and line/column. Numeric and common named HTML character references are mapped back to their source position. Direct callers may pass `source_name=`; compatibility `HTML(filename=...)` supplies it automatically. No system font is loaded automatically.

RustyBuzz shaping and Unicode bidi ordering are now the production text path. It covers the tested Latin ligatures and kerning, combining marks, Arabic, Hebrew, numbers and punctuation, inline direction boundaries, grapheme fallback, and explicit embedding/isolate controls. Bidi controls influence ordering without requiring a font glyph and are omitted from rendered text. Mixed text carries exact visible logical PDF `/ActualText`; pypdf and pdfminer currently ignore that marked content and may omit a space adjacent to RTL runs during extraction. The `experimental_shaping` constructor keyword remains accepted but no longer changes behavior.

General block, paragraph, Flex and Grid containers now resolve percentage margins/padding and fixed or percentage min/max dimensions against their containing block. Normal-flow sibling and parent/child margins collapse, including negative margins. `overflow:hidden` establishes a deterministic PDF clip while `overflow:visible` preserves all content. Per-side solid/dashed/dotted borders, rounded corners, modern RGB/HSL alpha forms and cumulative `opacity` are exported through PDF graphics states.

Block-level `position:absolute` now resolves fixed or percentage insets against the nearest positioned block, Flex or Grid content box; `position:fixed` resolves against and repeats on every page content box. Positioned painting is ordered by integer `z-index`, and an ancestor `overflow:hidden` clips it. `transform` supports length-based translate, scale and angle-based rotate functions and keeps PDF link/destination geometry aligned. Flex adds reverse directions, wrapping, grow/shrink/basis and cross/content alignment. Grid adds fixed, percentage, `fr`, `auto`, `minmax()` and integer `repeat()` tracks plus positive explicit placement and spans. Flex lines and Grid rows are atomic pagination units; sized items and height-constrained containers return controlled errors rather than splitting.

Tables now place cells with `rowspan` in an explicit column grid, honor `vertical-align: top | middle | bottom`, and repeat both `<thead>` and `<tfoot>` after page breaks. Connected spans in repeating groups are supported. A body rowspan group taller than the available page area is fragmented between complete text lines with its backgrounds and borders continued. Use `tfoot { display: table-row-group }` to render the footer once. A span that crosses an HTML row-group boundary still raises a controlled error.

`HTML.render(..., presentational_hints=True)` and `HTML.write_pdf(..., presentational_hints=True)` now apply table `cellpadding`, `cellspacing`, width/height, align/valign and border attributes. Author CSS keeps precedence. Direct `Renderer` callers can opt in with `Renderer(presentational_hints=True)`.

Text that cannot fit a line now raises a controlled error, including `white-space: nowrap` and `pre` overflow. Callers that previously relied on clipping must reduce text size, increase available width or choose a wrapping mode. This is a visual behavior change, while the Python API remains source compatible.

`HTML` now passes SVG images to the same validated path as the core `Renderer`; the old restricted Pillow placeholder rasterizer has been removed. Supported SVG content is retained as a vector PDF Form XObject, while SVG filter subtrees and embedded raster images remain raster where required. `Renderer(svg_dpi=144.0)` controls validation/fallback raster density. `Renderer(max_image_dpi=300)` optionally downsamples oversized raster images after CSS sizing; the default `None` preserves source pixels. Images support `object-fit: fill | contain | cover | none | scale-down` and keyword, percentage or length `object-position` values.

`Renderer(resource_loader=ResourceLoader(...))`, `HTML` and `CSS` route images, SVG and `@font-face` through the bounded loader. `HTML` and `CSS` additionally accept `url_fetcher=...`. HTTP(S) loading requires explicit scheme and host policy. A per-render `CancelToken` is propagated into direct-renderer resource reads and restored after preprocessing.

Paged-media additions include composable named-page pseudo-classes; text-only `position: running()`/`element()` and `string-set: content()` margin content; nested page counters; bleed/crop marks; and the break-boundary rule that `break-before` determines the requested side when it conflicts with a preceding `break-after`. PDF export now supports inline and general named destinations, hierarchical heading outlines, byte attachments, and UTC creation/modification dates. Attachments use `application/octet-stream` and are limited to 100 MB per export.
